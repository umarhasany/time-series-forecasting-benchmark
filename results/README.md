# Results

This folder stores the final measured outputs used by the README and figures.

- `accuracy_results.csv` - sMAPE, WAPE, and RMSE for ETS, LightGBM, and Chronos-2 on both datasets
- `uncertainty_results.csv` - target coverage, observed coverage, and mean interval width
- `computational_cost.csv` - task-specific fit time and inference time
- `covariate_results.csv` - M5 LightGBM baseline versus price/event/SNAP covariates

These files contain the recorded results from the completed Google Colab benchmark runs. Runtime measurements are hardware-dependent.
